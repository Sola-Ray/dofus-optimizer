# dofus-optimizer

Optimiseur de stuff Dofus 3 : choisit les équipements, la forgemagie (over/exo) et la répartition des caractéristiques pour maximiser les dégâts d'un ou plusieurs éléments, puis simule les jets (normaux et critiques) de tous les sorts de la classe contre une cible paramétrable.

Données : [DofusDB](https://dofusdb.fr) (`node scripts/fetch-data.mjs`).
